# Strengthening Roadmap v0.1

Status update — 2026-09-24: I0-I5a are complete and merged. A GitHub-native automation foundation is inserted before I5b so deterministic verification and repository coordination no longer default to Codex. See `github-native-execution-plan-2026-09-24.md`.

## Mandatory before first paid generation

### Phase I0–I3 — Production Reliability
Highest priority.

Implement:
- State Engine
- transaction recovery
- CAS revision/hash
- execution claim
- provider receipt
- cross-machine handoff
- external-processing policy
- provider-ready derivative provenance
- materialization/hash
- spend ledger
- prompt provenance

These are not optional enhancements; they are safety foundations.

## Phase I4–I5b — First practical intelligence

### Visual QC baseline
Implement deterministic/structured Q0–Q3 and manual-Web import first.

Do not build advanced AI visual QC yet.

### Provider runtime intelligence baseline
Capture:
- route
- model/mode
- reference pattern
- prompt transform
- candidate result
- credits
- usable seconds
- failure reason

This creates the data needed for later learning.

## GitHub automation foundation — before I5b

Use GitHub Actions, Issues/PR templates, Dependabot, GitHub Projects and general ChatGPT/GitHub coordination for routine repository work. GitHub Projects routes Issues by Phase and Execution owner; it is not a second source of truth. Codex is invoked only for implementation, local/provider execution or deep debugging.

Acceptance is defined in `github-native-execution-plan-2026-09-24.md`.

## After I5b + real production data — Provider Intelligence

Start only after one controlled paid pilot and several real shots.

Build:
- provider/mode success statistics
- failure taxonomy by route/model
- usable-seconds-per-credit
- average retries to approval
- reference strategy effectiveness
- sequence continuity outcomes

Use this to improve Router scoring. Do not hard-code temporary model rankings into the canonical schema.

## After I4 + enough reviewed outputs — Visual QC Intelligence

When enough human-reviewed examples exist, improve:
- identity drift detection
- body/camera/background drift
- exact text checks
- interaction checks
- expression/performance assistance
- edit-handle detection

Human creative approval remains authoritative.

## After stable I5b/I6 — Agent / Computer Use

Optional experimentation:
- Flow browser assistance
- PixVerse Canvas assisted workflows
- Adobe task assistance
- automated review/report preparation

Prefer deterministic CLI/API routes where available.

## Later / only if real need appears

- simultaneous multi-machine writers
- dashboards
- ComfyUI/local generation
- broad provider benchmarking
- autonomous cross-provider switching
- ChatGPT direct PixVerse execution if a real action connector becomes available

## Priority order

1. Completed reliability baseline (I0-I5a)
2. GitHub-native automation foundation + Projects coordination layer
3. I5b controlled paid pilot and measurable provider telemetry
4. I6 legacy migration/replay
5. I7 hardening/release readiness
6. Router learning from real production data
7. Visual QC intelligence
8. Computer-use convenience
9. Additional providers/local AI
